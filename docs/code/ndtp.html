NDTP-кодек (libs/ndtp)¶

Разбор и сборка кадров NDTP без внешних зависимостей; общий для backend и фидера.

NDTP (Navigation Data Transfer Protocol) codec.

Реализация по dataset/docs/Emulator-and-Telematic-Packets-Specification.md:

кадр = [ NPL 15 байт ][ NPH 10 байт ][ тело ]

  • все поля little-endian, структуры packed;

  • CRC-16/Modbus (poly 0xA001, init 0xFFFF) по NPH + телу, в NPL кладётся со свапнутыми байтами;

  • тело NPH_SND_REALTIME — последовательность ячеек [type u8][number u8][payload].

Модуль без внешних зависимостей: им пользуются и Backend-сервис (приём и разбор потока), и replay-фидер (кодирование CSV-телеметрии в NDTP). Один кодек на обеих сторонах гарантирует, что формат совпадает; совместимость с протоколом проверена захватами живого эмулятора (libs/ndtp/tests/fixtures).

class ndtp.codec.StreamDecoder(verify_crc=True, max_buffer=1048576)[исходный код]¶

Базовые классы: object

Инкрементальный декодер TCP-потока: накапливает байты, отдаёт целые кадры.

Устойчив к мусору и битым кадрам: при ошибке сигнатуры/CRC пересинхронизируется по следующей сигнатуре 0x7E7E, не теряя соединение.

Параметры:

  • verify_crc (bool)

  • max_buffer (int)

SIG = b'~~'¶
feed(data)[исходный код]¶

Добавляет очередной фрагмент TCP-потока и выдаёт все собранные целые кадры.

Параметры:

data (bytes) – Произвольный фрагмент (TCP не сохраняет границы кадров).

Yields:

Frame – Корректные кадры. Ошибки не пробрасываются, а считаются в errors и last_error.

Тип результата:

Iterator[Frame]

ndtp.codec.encode_nav(timestamp, lon, lat, valid, speed=0.0, heading=0.0, alt=0.0, nsat=12, pdop=10, bat_voltage_v=4.1, track_m=0)[исходный код]¶

G6CellNav00 из полей traffic.csv (обратное преобразование к таблице §8 README датасета).

Параметры:

  • valid (bool) – Координаты достоверны.

  • speed (float) – Скорость, км/ч.

  • heading (float) – Курс, градусы.

  • alt (float) – Высота, м.

  • nsat (int) – Число спутников.

  • pdop (int) – PDOP.

  • bat_voltage_v (float) – Напряжение батареи, В.

  • track_m (int) – Пробег, м.

Результат:

bytes – Ячейка Nav00.

Тип результата:

bytes
